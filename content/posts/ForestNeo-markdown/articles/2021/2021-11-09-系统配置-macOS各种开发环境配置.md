# Homebrew

官网给的安装方法为：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"
```

但是安装缓慢，连接失败，可以尝试以下方法，用中科大镜像加速访问：

```bash
/usr/bin/ruby -e "$(curl -fsSL https://cdn.jsdelivr.net/gh/ineo6/homebrew-install/install)"
```

然后会提示把brew添加到环境变量，运行这个语句：

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> /Users/forestneo/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

然后就可以查看版本了

```bash
brew -v
Homebrew 3.3.3
Homebrew/homebrew-core (no Git repository)
```

<a id="Git"></a>

# Git

macOS安装了Xcode之后就有git了，效果如下：

```bash
Last login: Tue Nov  9 09:15:14 on ttys003
forestneo@ForestNeo Desktop % git --version
git version 2.30.1 (Apple Git-130)
```

然后创建用户名、邮箱信息

```bash
git config --global user.name "your_name"  
git config --global user.email "your_email@youremail.com"
```

生成秘钥并查看

```bash
ssh-keygen -t rsa -C "your_email@youremail.com"
cat ~/.ssh/id_rsa.pub
```

然后去GitHub中添加新秘钥即可。

<a id="MySQL"></a>

# MySQL

下载链接：[https://dev.mysql.com/downloads/mysql/，下载了一路安装就可以安装成功了。然后打开终端输入](<https://dev.mysql.com/downloads/mysql/，下载了一路安装就可以安装成功了。然后打开终端输入>) `mysql` 发现没反应的。

![image-20211116102853637](<https://forest-pic.oss-cn-beijing.aliyuncs.com/webimg/202111161028696.png>)

需要进行这么几个操作：

- 如果是`bash`,执行`open ~/.bash_profile`；如果是`zsh`,执行`open ~/.zshrc`

- 添加语句`PATH=$PATH:/usr/local/mysql/bin`,保存

- 回到终端，让其立即生效，`source ~/.bash_profile` or `source ~/.zshrc`

![image-20211116102903163](<https://forest-pic.oss-cn-beijing.aliyuncs.com/webimg/202111161029192.png>)

![image-20211116103005247](<https://forest-pic.oss-cn-beijing.aliyuncs.com/webimg/202111161030277.png>)

这时候，在终端输入 `mysql` 就有反应了，但是会提示权限不够，需要输入：

```bash
mysql -uroot -p
```

然后就可以对 MySQL 进行操作了。

参考内容

- [https://www.jianshu.com/p/199492627ccc/](<https://www.jianshu.com/p/199492627ccc/>)

# Spark

参考了本篇博客：[https://www.cnblogs.com/bigdataZJ/p/hellospark.html](<https://www.cnblogs.com/bigdataZJ/p/hellospark.html>)

安装Spark之前需要安装Hadoop。首先运行`ssh localhost`测试是否可以运行成功，但是有一个问题就是每次都需要输入密码，所以配置一下使得以后不用重复输入账号密码。但我试了还是不太行，原来的命令还是放过来吧：

```bash
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
```

然后开始安装Hadoop，用以下命令：

```bash
brew install hadoop
```

运行完了之后，`/usr/local/Cellar`下面就有hadoop目录了。如果不放心可以再来一遍`brew install hadoop`，然后他就会告诉你安装成功了。我的路径和网上的不太一样，我的路径是：

```bash
pwd
/opt/homebrew/Cellar/hadoop/3.3.1/libexec/etc/hadoop
```

然后开始对Hadoop进行配置，进入安装目录，找到 hadoop-env.sh里面的`export HADOOP_OPTS="$HADOOP_OPTS -Djava.net.preferIPv4Stack=true"`，把它改成：

```bash
export HADOOP_OPTS="$HADOOP_OPTS -Djava.net.preferIPv4Stack=true -Djava.security.krb5.realm= -Djava.security.krb5.kdc="
export JAVA_HOME="/Library/Java/JavaVirtualMachines/jdk1.8.0_121.jdk/Contents/Home"
```

我的地址是可以从以下代码查看：

```bash
# 查找jdk地址
/usr/libexec/java_home -V
Matching Java Virtual Machines (1):
    17.0.1 (arm64) "Oracle Corporation" - "Java SE 17.0.1" /Library/Java/JavaVirtualMachines/jdk-17.0.1.jdk/Contents/Home
/Library/Java/JavaVirtualMachines/jdk-17.0.1.jdk/Contents/Home
```

然后开始配置hdfs地址和端口，进到同一个目录，打开`core-site.xml`，把 `<configuration></configuration>`，改成以下内容：

```xml
<configuration>
  <property>
     <name>hadoop.tmp.dir</name>
<value>/usr/local/Cellar/hadoop/hdfs/tmp</value>
    <description>A base for other temporary directories.</description>
  </property>
  <property>
     <name>fs.default.name</name>
     <value>hdfs://localhost:8020</value>
  </property>
</configuration>
```

注意到上面的路径不太一样，我改成了这个目录：

```xml
<configuration>
  <property>
     <name>hadoop.tmp.dir</name>
<value>/opt/homebrew/Cellar/hadoop/hdfs/tmp</value>
    <description>A base for other temporary directories.</description>
  </property>
  <property>
     <name>fs.default.name</name>
     <value>hdfs://localhost:8020</value>
  </property>
</configuration>
```

然后配置mapreduce中jobtracker的地址和端口  
在相同的目录下，你可以看到一个`mapred-site.xml.template`首先将文件重命名为`mapred-site.xml`，同样将`<configuration></configuration>`替换为

```xml
<configuration>
    <property>
        <name>mapred.job.tracker</name>
        <value>localhost:8021</value>
    </property>
</configuration>
```

接着修改hdfs备份数，相同目录下，打开`hdfs-site.xml`加上

```xml
<configuration>
   <property>
     <name>dfs.replication</name>
     <value>1</value>
    </property>
</configuration>
```

然后在这个目录运行`hdfs namenote -format`，结果如下：

![image-20220119203659335](<https://forest-pic.oss-cn-beijing.aliyuncs.com/webimg/202201192036403.png>)

然后配置环境变量，输入命令`vim ./.bash_profile`，加入以下内容，然后运行`source ~/.bash_profile`更新一下就好了。

```xml
export HADOOP_HOME=/opt/homebrew/Cellar/hadoop/3.3.1
export PATH=$PATH:$HADOOP_HOME/sbin:$HADOOP_HOME/bin
```
