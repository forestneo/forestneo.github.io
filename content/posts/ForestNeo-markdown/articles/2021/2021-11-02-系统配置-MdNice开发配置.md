MdNice的链接为：[https://github.com/mdnice/markdown-nice](<https://github.com/mdnice/markdown-nice>)

大致步骤为：

- 安装Nodejs

- 安装npm

- 安装yarn

node和npm的环境电脑里面已经安装好了，就介绍安装yarn的过程，可以通过npm进行安装，用以下几个命令就好了：

```
# 安装
npm install -g yarn --registry=https://registry.npm.taobao.org
# 配置源
yarn config set registry https://registry.npm.taobao.org -g
yarn config set sass_binary_site http://cdn.npm.taobao.org/dist/node-sass -g
# 查看版本
yarn -v
```

我的 yarn 的版本是 `1.22.17`

```bash
# 编译，好像有错误
npm run build

# 安装依赖
yarn

# 启动
yarn start
```
